# PROJECT TITLE:  Report on Olympic Sports (1896 - 2016)
# PURPOSE: Have a quick look on data of Olympic Sports via Dashboard
# Technology: Microsoft Power BI
# Data Source: Extracted from Search Engines. Then transformed according to requirement of columns to make the Dashboard.
# Problem: Takes too much time to analyze the data and extract the required information given in tabular form.
# Goal of Dashboard: To represent the data published in one sight using different Visuals, Charts, buttons, Slicers etc. in single platform and give required information in quick and easy way.
# Key Visuals: In this Dashboard, I designed two pages, in which we can navigate by pressing ctrl + Action button.
# In Page1: known as Home page I represent, 
Total Sports played, Total Team involved, Total medals distributed and Total number of participants via Card Visual.
Further, Count of Medals by Team & Medal Type and Count of Medals by Sport & Medal Type via Stacked Bar Chart.
Then, Count of Medals by Medal Type via Stacked Column Chart and Count of Medals by Gender via Donut Chart.
A Slicer to select the year/years for which we want to represent the data And a Action Button "Age Wise" to go to Page2.
# In Page2:  I represent,
The percentage of medals won by different age category (Age:10 -30 ,31-50,51-70,71-100).
Again, A Slicer to select the year/years for which we want to represent the data And a Action Button "Home Page" to go to Page1.
